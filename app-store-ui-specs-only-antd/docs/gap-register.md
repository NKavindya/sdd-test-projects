## Documented upstream facts preserved

- **ST-GAP-02:** Statistics percentages are not mounted.
- **ST-GAP-03:** Literal `R` is documented as defective copy, not intended UX. The feature’s current-user fallback is used without inventing replacement warning text.
- **ST-GAP-04:** Other versions deliberately open under `/store/android/apps/...`.
- **ST-GAP-05:** CUSTOM firmware has no artifact-download control.
- **ST-GAP-RH-01:** Safe login returns are restricted to same-origin `/store/...` targets.
- Install/uninstall cold URLs and reloads return home; hand-off exists only in memory.
- Catalogue hearts always render; release favourites require modify scope.
- Uninstall menu/candidates use uninstall scope; all subscription mutations use the install-scoped POST family. Server rejection remains authoritative.
- Firmware modal tabs ignore the app wizard hide-unauthorized rule; the firmware Device context remains android/CUSTOM.

## Binding decisions

Ant Design is pinned at 5.14.0. Only the listed public runtime packages needed by this implementation are used. Product marks come from the spec assets; Ant Design icons cover the specified controls, so no private icon or Entgra component package is needed. Consequently Nexus `.npmrc` is unnecessary for this dependency set. If a private Entgra dependency is introduced, add the exact Nexus registry from `system/ui-dependencies.md` before installing it.

The observed `react-router` 6 / `react-router-dom` 5 mismatch is acknowledged. This application consumes only the specified `react-router-dom` 5 API and its matching transitive router; it does not install a second incompatible router major.
